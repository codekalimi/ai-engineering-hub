How does RAG work end to end?

In one lineDocuments are split, embedded and stored ahead of time. For each question, the most relevant chunks are retrieved and put into the prompt, so the model answers from them.

Step by step
  1. Indexing runs ahead of time: load the sources, clean them, split them into chunks, embed each chunk, and store the vectors with metadata (source, date, permissions).
  2. At question time, a chat follow-up is first rewritten into a standalone search query.
  3. Retrieval finds candidate chunks using vector and/or keyword search, filtered by the user's permissions.
  4. A reranker picks the most relevant few.
  5. The chunks and question are combined into a prompt that tells the model to answer only from the context and cite its sources.
  6. The model generates the answer, and the citations link back to the source documents.
Key details
  • Most quality problems are retrieval problems, so always log what was retrieved.
  • Evaluate retrieval (was the right chunk found?) separately from generation (was the answer faithful?).
  • Keep the index fresh with document IDs and content hashes.

Use it

What you'd write at work

Retrieve, put the chunks in the prompt, answer with citations. Most production RAG is this function plus good data and evals.

python
from langchain.chat_models import init_chat_model
from langchain.embeddings import init_embeddings
from langchain_core.vectorstores import InMemoryVectorStore

store = InMemoryVectorStore(init_embeddings("openai:text-embedding-3-small"))
store.add_texts(
    ["Employees get 24 days of paid leave per year.", "Laptops are replaced every 3 years.",
     "Book flights through the travel portal."],
    metadatas=[{"source": "hr-policy.md"}, {"source": "it-policy.md"}, {"source": "travel.md"}],
)
model = init_chat_model("anthropic:claude-opus-5-5")

def answer(question):
    docs = store.similarity_search(question, k=2)
    context = "\n".join(f"[{d.metadata['source']}] {d.page_content}" for d in docs)
    reply = model.invoke([("system", f"Answer only from this context and cite the source.\n\n{context}"),
                          ("human", question)])
    return reply.content, [d.metadata["source"] for d in docs]

print(answer("How many days of paid leave do I get?"))

✓ Ran with langchain 1.5.2, langchain-core 1.8.4 · with a scripted chat model in place of the API; a local embedding model (all-MiniLM-L6-v2) in place of the embedding API.

What it printed
('You get 24 days of paid leave per year [hr-policy.md].', ['hr-policy.md', 'it-policy.md'])

Under the hood

What the library does for you, with its real classes

The pieces behind that function: Documents with metadata, splitting, indexing, a metadata filter for permissions, and the exact messages the model receives.

python
from langchain.chat_models import init_chat_model
from langchain.embeddings import init_embeddings
from langchain_core.documents import Document
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_text_splitters import RecursiveCharacterTextSplitter

# Step 1 (indexing, ahead of time): documents keep their metadata through every step
raw = [Document("Employees get 24 days of paid leave per year. Unused leave carries over up to 5 days.",
                metadata={"source": "hr-policy.md", "team": "all"}),
       Document("Executive bonus pool is 2M this year.", metadata={"source": "finance.md", "team": "finance"})]
chunks = RecursiveCharacterTextSplitter(chunk_size=60, chunk_overlap=0).split_documents(raw)
store = InMemoryVectorStore(init_embeddings("openai:text-embedding-3-small"))
store.add_documents(chunks)
print(f"{len(raw)} documents -> {len(chunks)} chunks:", [c.page_content for c in chunks])

# Step 3: retrieval, filtered to what this user may see
question = "How many days of paid leave do I get?"
docs = store.similarity_search(question, k=2, filter=lambda d: d.metadata["team"] == "all")

# Step 5: the prompt template turns context + question into messages
prompt = ChatPromptTemplate.from_messages([
    ("system", "Answer only from the context. Cite the source in brackets.\n\n{context}"),
    ("human", "{question}"),
])
messages = prompt.invoke({"context": "\n".join(f"[{d.metadata['source']}] {d.page_content}" for d in docs),
                          "question": question}).to_messages()
for m in messages:
    print(f"--- {m.type} ---\n{m.content}")
print("--- answer ---\n" + init_chat_model("anthropic:claude-opus-5-5").invoke(messages).content)   # Step 6

✓ Ran with langchain 1.5.2, langchain-core 1.8.4, langchain-text-splitters 1.2.0 · with a scripted chat model in place of the API; a local embedding model (all-MiniLM-L6-v2) in place of the embedding API.

From scratch

The idea in plain Python, no libraries

A tiny version of the mechanism. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: nothing to install.

python3 · standard library only
# A whole RAG pipeline in miniature. Retrieval is word overlap instead of embeddings and the
# "LLM" is a stub, so you can see exactly what gets built and passed along.
import re

DOCS = {
    "hr-policy.md": "Employees get 24 days of paid leave per year. Unused leave carries over up to 5 days.",
    "it-policy.md": "Laptops are replaced every 3 years. Report lost devices to IT within 24 hours.",
    "travel.md": "Book flights through the travel portal. Economy class for flights under 6 hours.",
}
def words(t): return set(re.findall(r"[a-z0-9]+", t.lower()))

# Step 1 (indexing, ahead of time): split into chunks and index them
chunks = [(src, s.strip()) for src, text in DOCS.items() for s in text.split(". ") if s.strip()]
index = [(src, text, words(text)) for src, text in chunks]
print(f"indexed {len(index)} chunks")

# Step 2: a chat follow-up would be rewritten into a standalone question here
question = "How many days of paid leave do I get?"
# Step 3: retrieval - score every chunk
q = words(question)
scored = sorted(((len(q & w), src, text) for src, text, w in index), reverse=True)
# Step 4: "rerank" - keep the best 2 that match at all
top = [(src, text) for score, src, text in scored[:2] if score > 0]
# Step 5: build the prompt: numbered, labelled context plus the instruction
context = "\n".join(f"[{i + 1}] ({src}) {text}" for i, (src, text) in enumerate(top))
prompt = f"Answer only from the context. Cite like [1].\n\nContext:\n{context}\n\nQuestion: {question}"
print("---- prompt sent to the LLM ----\n" + prompt + "\n--------------------------------")

# Step 6: the LLM answers from the context with a citation (stubbed)
def fake_llm(prompt):
    return context.splitlines()[0].split(") ", 1)[1] + " [1]"
print("answer:", fake_llm(prompt))

✓ Ran with plain Python 3.9+.

Watch it in a real system
  • LangChain: from langchain_core.globals import set_debug; set_debug(True) prints every step’s input and output, including the final prompt with the retrieved chunks.
  • LangSmith: set LANGSMITH_TRACING=true and LANGSMITH_API_KEY; each run shows the retriever’s documents and the exact prompt sent to the model.
  • Always print the retrieved chunks next to the answer while developing: most bad answers are bad retrieval.
