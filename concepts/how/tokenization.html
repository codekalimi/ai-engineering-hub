How does tokenization (BPE) work?

In one lineByte-pair encoding builds a vocabulary of frequent character sequences. Text is split into the longest known pieces, so common words are one token and rare words become several.

Step by step
  1. Training starts from raw bytes, so any text can be represented and there are no unknown words.
  2. It repeatedly merges the most frequent adjacent pair into a new token, building up common chunks like "ing" or " the".
  3. At run time, text is split into the vocabulary's pieces and each piece becomes an ID.
  4. Every model family has its own tokenizer, so the same text has different token counts on different models.
Key details
  • English averages about 4 characters per token; code, numbers and many other languages need more.
  • The model sees pieces, not letters. That's why it can miscount the letters in a word.
  • Count tokens with the provider's tokenizer or token-counting endpoint before sending large inputs.
  • The example IDs above are illustrative; real IDs depend on the tokenizer.

Use it

What you'd write at work

Count tokens before sending big inputs. Each model family has its own tokenizer; for Claude use the API's count endpoint: client.messages.count_tokens(model=..., messages=...).

python
import tiktoken

enc = tiktoken.get_encoding("o200k_base")          # the tokenizer used by recent OpenAI models
for text in ["unbelievable", "The cat sat on the mat.", "def add(a, b): return a + b"]:
    ids = enc.encode(text)
    print(f"{len(text):2} chars -> {len(ids)} tokens: {[enc.decode([i]) for i in ids]}")
print("Hindi:", len(enc.encode("नमस्ते दुनिया")), "tokens for 13 characters")

✓ Ran with tiktoken 0.14.0.

Under the hood

What the library does for you, with its real classes

Inside a Hugging Face tokenizer: a byte-level BPE vocabulary plus the ordered merge rules learned in training.

python
import json
from transformers import AutoTokenizer

tok = AutoTokenizer.from_pretrained("Qwen/Qwen2.5-0.5B-Instruct")
spec = json.loads(tok.backend_tokenizer.to_str())["model"]
# Step 2's result: a vocabulary plus merge rules, applied in order
print(spec["type"], "- vocabulary", len(spec["vocab"]), "pieces,", len(spec["merges"]), "merge rules")

pieces = tok.tokenize("unbelievable tokenization")   # Step 3: split into known pieces
print(pieces)                                         # 'Ġ' marks a leading space
print(tok.convert_tokens_to_ids(pieces))              # ...and each piece becomes an id
# Step 1: byte-level, so any text works - even emoji - and nothing is "unknown"
print(tok.tokenize("🙂"), "->", tok.decode(tok.encode("🙂")))

✓ Ran with transformers 5.24.0.

From scratch

The idea in plain Python, no libraries

A tiny version of the mechanism. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: nothing to install.

python3 · standard library only
# Train a tiny BPE tokenizer, then use it.
from collections import Counter

corpus = "low lower lowest newer newest wider widest"
# Step 1: start from single characters (real BPE starts from bytes). "_" marks the end of a word.
words = Counter(tuple(w) + ("_",) for w in corpus.split())

def pair_counts(words):
    counts = Counter()
    for word, freq in words.items():
        for a, b in zip(word, word[1:]):
            counts[a, b] += freq
    return counts

def merge(word, pair):
    out, i = [], 0
    while i < len(word):
        if i < len(word) - 1 and (word[i], word[i + 1]) == pair:
            out.append(word[i] + word[i + 1])
            i += 2
        else:
            out.append(word[i])
            i += 1
    return tuple(out)

# Step 2: repeatedly merge the most frequent adjacent pair into a new token
merges = []
for _ in range(8):
    best, n = pair_counts(words).most_common(1)[0]
    merges.append(best)
    words = Counter({merge(w, best): f for w, f in words.items()})
    print(f"merge {best[0]!r} + {best[1]!r} (seen {n}x)")

# Step 3: tokenize new text by replaying the merges in order; each piece gets an ID
def tokenize(word):
    parts = tuple(word) + ("_",)
    for pair in merges:
        parts = merge(parts, pair)
    return list(parts)

vocab = {}
for w in ["lowest", "newest", "slower"]:
    pieces = tokenize(w)
    ids = [vocab.setdefault(p, len(vocab)) for p in pieces]
    print(f"{w!r:10} -> {pieces} -> ids {ids}")

✓ Ran with plain Python 3.9+.
