How does tokenization (BPE) work?

In one lineByte-pair encoding builds a vocabulary of frequent character sequences. Text is split into the longest known pieces, so common words are one token and rare words become several.

Step by step
  1. Training starts from raw bytes, so any text can be represented and there are no unknown words.
  2. It repeatedly merges the most frequent adjacent pair into a new token, building up common chunks like "ing" or " the".
  3. At run time, text is split into the vocabulary's pieces and each piece becomes an ID.
  4. Every model family has its own tokenizer, so the same text has different token counts on different models.
Key details
  • English averages about 4 characters per token; code, numbers and many other languages need more.
  • The model sees pieces, not letters. That's why it can miscount the letters in a word.
  • Count tokens with the provider's tokenizer or token-counting endpoint before sending large inputs.
