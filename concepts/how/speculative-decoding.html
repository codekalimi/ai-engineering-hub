How does speculative decoding work?

In one lineA small, fast model drafts several tokens ahead; the large model checks all of them in one pass and keeps the ones it agrees with, giving several tokens for the price of one big step.

Step by step
  1. A small draft model (or extra prediction heads) quickly proposes the next few tokens.
  2. The large model processes all of them in a single forward pass, getting its own prediction for each position.
  3. Draft tokens are accepted up to the first one the large model disagrees with.
  4. At that position, the large model's own token is used, and drafting starts again.
Key details
  • The output is the same as the large model alone would produce; only speed changes.
  • The speed-up depends on how often the draft is right: high for predictable text like code.
Behind the scenes

See it run

A tiny from-scratch version of what really happens. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: plain Python, nothing to install.

python3 · standard library only
import random
random.seed(5)
TARGET = "the quick brown fox jumps over the lazy dog".split()

def big_model(prefix):
    # the slow, accurate model (here it always knows the right next word)
    return TARGET[len(prefix)] if len(prefix) < len(TARGET) else None

def draft_model(prefix, k):
    # Step 1: a small, fast model guesses the next k tokens; sometimes it is wrong
    return [TARGET[p] if random.random() < 0.75 else "cat"
            for p in range(len(prefix), min(len(prefix) + k, len(TARGET)))]

out, big_passes = [], 0
while len(out) < len(TARGET):
    draft = draft_model(out, k=4)
    big_passes += 1                      # Step 2: ONE big-model pass checks every draft token
    accepted = []
    for tok in draft:
        want = big_model(out + accepted)
        if tok == want:
            accepted.append(tok)         # Step 3: accept up to the first disagreement
        else:
            accepted.append(want)        # Step 4: use the big model's own token there, then redraft
            break
    else:
        bonus = big_model(out + accepted)  # all accepted: the same pass yields one extra token
        if bonus:
            accepted.append(bonus)
    print(f"pass {big_passes}: draft {draft} -> keep {accepted}")
    out += accepted
print(f"{len(out)} tokens in {big_passes} big-model passes (normal decoding needs {len(TARGET)})")
What it prints
pass 1: draft ['the', 'quick', 'cat', 'cat'] -> keep ['the', 'quick', 'brown']
pass 2: draft ['fox', 'cat', 'over', 'the'] -> keep ['fox', 'jumps']
pass 3: draft ['cat', 'the', 'cat', 'dog'] -> keep ['over']
pass 4: draft ['the', 'lazy', 'dog'] -> keep ['the', 'lazy', 'dog']
9 tokens in 4 big-model passes (normal decoding needs 9)
Watch it in a real system
  • vLLM: configure a draft model or n-gram/EAGLE speculation (see the speculative decoding docs for your version) and compare tokens/second on the same prompts.
  • Watch the acceptance rate in its metrics/logs: high for predictable text (code, JSON, repeated content), low for creative writing.
