How does speculative decoding work?

In one lineA small, fast model drafts several tokens ahead; the large model checks all of them in one pass and keeps the ones it agrees with, giving several tokens for the price of one big step.

Step by step
  1. A small draft model (or extra prediction heads) quickly proposes the next few tokens.
  2. The large model processes all of them in a single forward pass, getting its own prediction for each position.
  3. Draft tokens are accepted up to the first one the large model disagrees with.
  4. At that position, the large model's own token is used, and drafting starts again.
Key details
  • The output is the same as the large model alone would produce; only speed changes.
  • The speed-up depends on how often the draft is right: high for predictable text like code.
