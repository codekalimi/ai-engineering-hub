How does RAG handle follow-up questions in a chat?

In one lineA follow-up like "what about the second one?" can't be searched as it is, so an LLM first rewrites it into a standalone question using the chat history, and that's what gets retrieved.

Step by step
  1. The user's new message often only makes sense with the earlier turns.
  2. A small, fast model rewrites it into a self-contained question, using the history.
  3. Retrieval runs on the rewritten question.
  4. The final answer is generated from the retrieved context plus the conversation.
Key details
  • Skip the rewrite for the first message of a conversation to save latency.
  • Log the rewritten query; it's a common hidden failure point.
  • Multi-query (several rewrites, results merged) can improve recall further.
