How does LoRA fine-tuning work?

In one lineThe original weights are frozen; two small trainable matrices are added beside them, and only those are trained. Their product is a low-rank update to the original weights.

Step by step
  1. The pretrained weight matrix W is frozen and isn't updated.
  2. Two small matrices are added: A shrinks the input to a small rank r, and B expands it back.
  3. The layer's output is W·x plus B·A·x.
  4. Only A and B are trained: a tiny fraction of the parameters, so memory and storage drop dramatically.
  5. After training, B·A can be merged into W, or kept separate as a swappable adapter.
Key details
  • QLoRA keeps the frozen W in 4-bit, allowing fine-tuning of large models on one GPU.
  • Multi-LoRA serving runs many adapters on one base model.
  • Higher rank r means more capacity but more memory.

Use it

What you'd write at work

Wrap a model with PEFT: the base weights freeze and small adapters are added to the layers you name.

python
from peft import LoraConfig, get_peft_model
from transformers import AutoModelForCausalLM

model = AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-0.5B-Instruct")
config = LoraConfig(r=16, lora_alpha=32, lora_dropout=0.05,
                    target_modules=["q_proj", "k_proj", "v_proj", "o_proj"], task_type="CAUSAL_LM")
model = get_peft_model(model, config)
model.print_trainable_parameters()
print(model.base_model.model.model.layers[0].self_attn.q_proj)     # the wrapped layer
# after training: model.save_pretrained("adapter/")  (a few MB)  or  model.merge_and_unload()

✓ Ran with peft 0.22.0, transformers 5.24.0.

Under the hood

What the library does for you, with its real classes

A LoRA layer written by hand around a real Qwen projection: frozen W, trainable A and B, output W x + (alpha/r) B A x. Then a training step and the merge.

python
import torch
from transformers import AutoModelForCausalLM

base = AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-0.5B-Instruct", dtype=torch.float32).model.layers[0].self_attn.q_proj
base.requires_grad_(False)                                         # Step 1: W is frozen
W_before = base.weight.detach().clone()

class LoRALinear(torch.nn.Module):
    def __init__(self, base, r=8, alpha=16):
        super().__init__()
        self.base, self.scale = base, alpha / r
        self.A = torch.nn.Parameter(torch.randn(r, base.in_features) * 0.01)   # Step 2: down to rank r
        self.B = torch.nn.Parameter(torch.zeros(base.out_features, r))         #         back up (starts at 0)
    def forward(self, x):
        return self.base(x) + self.scale * (x @ self.A.T @ self.B.T)          # Step 3: W x + B A x

layer = LoRALinear(base)
x = torch.randn(2, base.in_features)
print("at start, same as the base layer:", torch.allclose(layer(x), base(x)))
trainable = sum(p.numel() for p in layer.parameters() if p.requires_grad)
print(f"trainable {trainable:,} of {trainable + base.weight.numel():,} weights ({trainable / base.weight.numel():.1%})")

opt = torch.optim.AdamW([layer.A, layer.B], lr=1e-2)              # Step 4: only A and B are updated
loss = (layer(x) - torch.randn_like(layer(x))).pow(2).mean()
loss.backward()
opt.step()
print("after one step - W changed:", not torch.equal(base.weight, W_before), "| B changed:", bool(layer.B.abs().sum() > 0))

merged = base.weight + layer.scale * (layer.B @ layer.A)          # Step 5: fold B A into W
print("merged layer gives the same output:", torch.allclose(x @ merged.T + (base.bias if base.bias is not None else 0), layer(x), atol=1e-4))

✓ Ran with torch 2.15.0, transformers 5.24.0.

What it printed

after one step - W changed: False | B changed: True

From scratch

The idea in plain Python, no libraries

A tiny version of the mechanism. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: nothing to install.

python3 · standard library only
import random
random.seed(0)

d, r = 8, 2                                      # an 8x8 layer, LoRA rank 2
W = [[random.uniform(-1, 1) for _ in range(d)] for _ in range(d)]   # Step 1: frozen pretrained weights
A = [[random.gauss(0, 0.1) for _ in range(d)] for _ in range(r)]    # Step 2: A shrinks d -> r
B = [[0.0] * r for _ in range(d)]                                   #         B expands r -> d, starts at 0
matvec = lambda M, v: [sum(a * b for a, b in zip(row, v)) for row in M]

def forward(x):
    # Step 3: output = W x + B (A x)
    return [w + l for w, l in zip(matvec(W, x), matvec(B, matvec(A, x)))]

x = [1.0] * d
print("before training the adapter changes nothing (B = 0):", forward(x) == matvec(W, x))

# Step 4: only A and B are trained
full, lora = d * d, d * r + r * d
print(f"this layer: full fine-tune {full} weights, LoRA {lora} ({lora / full:.0%})")
D = 4096
print(f"a 4096x4096 layer: full {D * D:,} weights, LoRA r=16 {2 * D * 16:,} ({2 * D * 16 / (D * D):.2%})")

# pretend training changed B; Step 5: merge B·A into W so inference costs nothing extra
B = [[0.1 * (i - j) for j in range(r)] for i in range(d)]
BA = [[sum(B[i][k] * A[k][j] for k in range(r)) for j in range(d)] for i in range(d)]
W_merged = [[W[i][j] + BA[i][j] for j in range(d)] for i in range(d)]
same = all(abs(a - b) < 1e-9 for a, b in zip(forward(x), matvec(W_merged, x)))
print("merged W gives the same output as W + adapter:", same)

✓ Ran with plain Python 3.9+.
