How does recursive text splitting work?

In one lineIt splits on the biggest natural boundary first (paragraphs) and only falls back to smaller ones (lines, words, characters) for pieces that are still too big, then adds overlap.

Step by step
  1. The splitter has an ordered list of separators: by default paragraph break, line break, space, then single characters.
  2. It splits on the first separator and checks the size of each piece.
  3. Pieces that are still too large are split again with the next separator.
  4. Small neighbouring pieces are merged back together up to chunk_size, so chunks aren't tiny.
  5. Each chunk repeats the end of the previous one (overlap), so an idea crossing a boundary isn't lost.
Key details
  • Sizes are in characters unless you use a token-based length function.
  • Structure-aware splitters (markdown headings, code syntax) often do better.
  • Store the chunk's position and parent document ID, for citations and for expanding context later.

Use it

What you'd write at work

Split documents before embedding them. Keep metadata, and record where each chunk starts so citations can point back.

python
from langchain_core.documents import Document
from langchain_text_splitters import RecursiveCharacterTextSplitter

doc = Document(
    "RAG systems split documents into chunks.\n\nEach chunk is embedded separately. Chunks that are too "
    "big blur the meaning; chunks that are too small lose context.\n\nOverlap repeats a little text.",
    metadata={"source": "guide.md"},
)
splitter = RecursiveCharacterTextSplitter(chunk_size=80, chunk_overlap=20, add_start_index=True)
for c in splitter.split_documents([doc]):
    print(c.metadata, repr(c.page_content))

✓ Ran with langchain-core 1.8.4, langchain-text-splitters 1.2.0.

Under the hood

What the library does for you, with its real classes

The splitter's real knobs: its separator list (Step 1), language-aware separators for code, and measuring size in tokens instead of characters.

python
from langchain_text_splitters import Language, RecursiveCharacterTextSplitter

print("default separators:", RecursiveCharacterTextSplitter()._separators)           # Step 1
print("python separators: ", RecursiveCharacterTextSplitter.get_separators_for_language(Language.PYTHON)[:4])

code = '''class Cart:
    def add(self, item):
        self.items.append(item)

    def total(self):
        return sum(i.price for i in self.items)

def checkout(cart):
    return cart.total()
'''
py = RecursiveCharacterTextSplitter.from_language(Language.PYTHON, chunk_size=90, chunk_overlap=0)
for c in py.split_text(code):                                      # Steps 2-4: split at def/class first
    print("---\n" + c)

by_tokens = RecursiveCharacterTextSplitter.from_tiktoken_encoder(encoding_name="o200k_base", chunk_size=12, chunk_overlap=3)
print([c for c in by_tokens.split_text("Chunk size can be measured in tokens, which is what the embedding model actually limits.")])

From scratch

The idea in plain Python, no libraries

A tiny version of the mechanism. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: nothing to install.

python3 · standard library only
# A small version of LangChain's RecursiveCharacterTextSplitter.
text = ("RAG systems split documents into chunks.\n\nEach chunk is embedded separately. "
        "Chunks that are too big blur the meaning; chunks that are too small lose context.\n\n"
        "Overlap repeats a little text between neighbouring chunks.")
# Step 1: an ordered list of separators, from biggest to smallest
SEPARATORS = ["\n\n", "\n", ". ", " ", ""]

def split(text, size, seps=SEPARATORS):
    # Step 2: split on the first separator
    sep, rest = seps[0], seps[1:]
    pieces = [p for p in (text.split(sep) if sep else list(text)) if p]
    small = []
    for p in pieces:
        # Step 3: pieces still too big are split again with the next separator
        small.extend([p] if len(p) <= size else split(p, size, rest))
    # Step 4: merge small neighbours back together, up to the chunk size
    chunks, cur = [], ""
    for p in small:
        candidate = cur + sep + p if cur else p
        if len(candidate) <= size:
            cur = candidate
        else:
            chunks.append(cur)
            cur = p
    return chunks + ([cur] if cur else [])

def add_overlap(chunks, n_words=3):
    # Step 5: start each chunk with the last few words of the previous one
    return [chunks[0]] + [" ".join(prev.split()[-n_words:]) + " ... " + c for prev, c in zip(chunks, chunks[1:])]

for i, c in enumerate(add_overlap(split(text, 70)), 1):
    print(f"chunk {i} ({len(c)} chars): {c!r}")

✓ Ran with plain Python 3.9+.
