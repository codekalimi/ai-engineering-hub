How are LLMs trained, from pretraining to assistant?

In one lineFirst the model learns language by predicting the next token on huge amounts of text; then it learns to follow instructions from examples; then it's tuned towards the answers people prefer.

Step by step
  1. Pretraining: the model reads trillions of tokens, and every wrong next-token prediction adjusts its billions of weights slightly. This is by far the most expensive stage.
  2. The result is a base model: excellent at continuing text, but not at following instructions.
  3. Supervised fine-tuning (SFT) trains it on curated instruction–response pairs, so it behaves like an assistant.
  4. Preference tuning: people (or AI) compare pairs of answers, and the model is trained to prefer the better ones (RLHF or DPO).
  5. Safety training, and reinforcement learning on checkable tasks such as maths and code, are added on top.
Key details
  • Most knowledge comes from pretraining, which is why models have a knowledge cutoff date.
  • Fine-tuning shapes behaviour much more than it adds facts.
  • See the Training & fine-tuning section for SFT, RLHF/DPO and LoRA in detail.
Behind the scenes

See it run

A tiny from-scratch version of what really happens. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: plain Python, nothing to install.

python3 · standard library only
# One tiny model, trained twice: pretraining on raw text, then SFT on an instruction example.
# The model is a table of scores: next token = softmax(W[previous token]).
import math

def train(W, pairs, epochs, label, lr=0.5):
    for epoch in range(epochs):
        loss = 0.0
        for prev, nxt in pairs:
            row = W.setdefault(prev, {t: 0.0 for t in VOCAB})
            exps = {t: math.exp(s) for t, s in row.items()}
            z = sum(exps.values())
            loss += -math.log(exps[nxt] / z)              # cross-entropy: surprise at the right token
            for t in VOCAB:                               # gradient step on the scores
                row[t] -= lr * (exps[t] / z - (1.0 if t == nxt else 0.0))
        if epoch in (0, epochs - 1):
            print(f"{label} epoch {epoch + 1:2}: loss {loss / len(pairs):.3f}")

def pairs_of(text):
    toks = text.split()
    return list(zip(toks, toks[1:]))

def predict(W, prev):
    row = W.get(prev, {})
    return max(row, key=row.get) if row else None

web = ("paris is the capital of france . the capital of france is paris . "
       "what is the capital of spain ? what is the capital of italy ?")
sft = "what is the capital of france ? answer : paris ."
VOCAB = sorted(set(web.split()) | set(sft.split()))
W = {}
# Step 1: pretraining - learn to continue text
train(W, pairs_of(web), 30, "pretrain")
# Step 2: a base model continues text; after "?" it expects another question
print("base model: after '?' comes", repr(predict(W, "?")))
# Step 3: SFT on instruction -> answer examples
train(W, pairs_of(sft) * 5, 30, "sft     ")
print("after SFT:  after '?' comes", repr(predict(W, "?")))
# Steps 4-5 (preference tuning, RL) - see the RLHF/DPO page
