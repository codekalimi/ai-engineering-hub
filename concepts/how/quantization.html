How does quantization work?

In one lineWeights are stored as small integers plus a scale factor per group, cutting memory 2–4×, and are converted back (or computed directly) at run time.

How to read this diagram

Flow diagram: read left to right. Dashed loops show steps that repeat; ↓ joins rows that follow on from each other.

Step by step
  1. Weights are grouped (per channel, or per group of around 128 values).
  2. For each group, a scale is chosen so its values fit the integer range (e.g. -127 to 127 for INT8).
  3. Each weight is divided by the scale and rounded to an integer.
  4. Only the integers and the scales are stored.
  5. At run time, kernels multiply back by the scale, or compute directly in low precision on supporting hardware.
Key details
  • Methods like GPTQ and AWQ choose the rounding carefully to minimize the error on important weights.
  • 8-bit is usually close to lossless; 4-bit saves more but can hurt quality, so check with evals.
  • The KV cache can be quantized too, which helps with long contexts.

Use it

What you'd write at work

Load a model in 4 bits with one config object. NF4 with bfloat16 compute is the common choice for QLoRA and for fitting big models on small GPUs.

python
import torch
from transformers import AutoModelForCausalLM, BitsAndBytesConfig

config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",               # 4-bit "normal float" levels, fitted to weight distributions
    bnb_4bit_compute_dtype=torch.bfloat16,   # weights are dequantized to bf16 inside each matmul
)
model = AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-7B-Instruct", quantization_config=config, device_map="auto")
print(f"{model.get_memory_footprint() / 1e9:.1f} GB in memory (about 15 GB in bf16)")

Checked, not run: bitsandbytes 4-bit loading needs an NVIDIA GPU; syntax and imports were checked.

Under the hood

What the library does for you, with its real classes

Group-wise int4 quantization of a real weight matrix from Qwen, by hand: the error it adds, and how small groups protect against outliers.

python
import torch
from transformers import AutoModelForCausalLM

model = AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-0.5B-Instruct")
W = model.model.layers[0].self_attn.q_proj.weight.detach().float()     # a real 896 x 896 weight
x = torch.randn(4, W.shape[1])

def quantize(W, bits, group):
    qmax = 2 ** (bits - 1) - 1
    groups = W.reshape(-1, group)                                       # Step 1: groups of weights
    scale = groups.abs().amax(dim=1, keepdim=True) / qmax               # Step 2: one scale per group
    q = torch.clamp(torch.round(groups / scale), -qmax - 1, qmax)       # Step 3: round to integers
    return q.to(torch.int8), scale                                      # Step 4: store ints + scales

def dequantize(q, scale, shape):
    return (q.float() * scale).reshape(shape)                           # Step 5: multiply back

print(f"weight {tuple(W.shape)}, largest |w| {W.abs().max():.2f}, typical |w| {W.abs().mean():.3f}")
for bits, group in [(8, 896), (4, 896), (4, 128), (4, 32)]:
    q, s = quantize(W, bits, group)
    W_hat = dequantize(q, s, W.shape)
    err = ((x @ W_hat.T) - (x @ W.T)).abs().mean() / (x @ W.T).abs().mean()
    size = W.numel() * bits / 8 + s.numel() * 2
    print(f"int{bits}, groups of {group:3}: output error {err:6.2%}, {size / 1e6:.2f} MB (bf16: {W.numel() * 2 / 1e6:.2f} MB)")

✓ Ran with torch 2.15.0, transformers 5.24.0.

From scratch

The idea in plain Python, no libraries

A tiny version of the mechanism. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: nothing to install.

python3 · standard library only
import random
random.seed(4)

weights = [random.gauss(0, 0.02) for _ in range(256)]
weights[10] = 0.31                                   # one outlier, as real models have

def quantize(ws, group, bits):
    qmax = 2 ** (bits - 1) - 1                       # 127 for int8, 7 for int4
    out = []
    for g in range(0, len(ws), group):               # Step 1: work per group of weights
        chunk = ws[g:g + group]
        scale = max(abs(w) for w in chunk) / qmax    # Step 2: a scale so the group fits the range
        q = [round(w / scale) for w in chunk]        # Step 3: divide and round to integers
        out.append((scale, q))                       # Step 4: store the integers + one scale per group
    return out

def dequantize(groups):
    return [qi * scale for scale, q in groups for qi in q]   # Step 5: multiply back at run time

for bits, group in [(8, 128), (4, 128), (4, 32)]:
    restored = dequantize(quantize(weights, group, bits))
    err = sum(abs(a - b) for a, b in zip(weights, restored)) / len(weights)
    print(f"int{bits}, groups of {group:3}: average error {err:.5f}")
print("smaller groups contain the outlier's damage to fewer weights")
for name, bytes_per_weight in [("FP16", 2), ("INT8", 1), ("INT4", 0.5)]:
    print(f"70B model in {name}: {70e9 * bytes_per_weight / 1e9:.0f} GB of weights")

✓ Ran with plain Python 3.9+.
