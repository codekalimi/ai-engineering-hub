How does an LLM gateway handle a request?

In one lineEvery app calls one internal API; the gateway authenticates the team, enforces limits, checks the cache, routes to the right model, falls back on errors and records usage.

Step by step
  1. Apps call the gateway with a model alias instead of a specific provider and model.
  2. The gateway authenticates the team and checks its rate limits and budget.
  3. It can return a cached response for repeated requests.
  4. It maps the alias to a provider and model, and calls it.
  5. On errors or timeouts it retries or falls back to another provider.
  6. It records tokens, cost, latency and team for every request.
Key details
  • Model upgrades become one central change behind an eval gate.
  • A natural place for PII redaction, logging policy and guardrails.
  • It's on every request's path, so it must be highly available and add little latency.
Behind the scenes

See it run

A tiny from-scratch version of what really happens. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: plain Python, nothing to install.

python3 · standard library only
import random
random.seed(1)

ALIASES = {"smart": [("provider-a", "big-model"), ("provider-b", "big-model-2")]}   # primary, fallback
BUDGET, SPENT = {"team-search": 1.00}, {"team-search": 0.0}
CACHE, LOG = {}, []

def call_provider(provider, model, prompt):
    if provider == "provider-a" and random.random() < 0.7:
        raise TimeoutError(f"{provider} timed out")
    return f"[{model}] answer to {prompt!r}", 120             # text, tokens

def gateway(team, alias, prompt):
    # Step 1: the app asked for an alias, not a provider. Step 2: auth, rate limit, budget
    if SPENT[team] >= BUDGET[team]:
        return "429 budget exceeded"
    # Step 3: cached response for an identical request
    if (alias, prompt) in CACHE:
        LOG.append((team, "cache", 0))
        return CACHE[alias, prompt] + " (from cache)"
    # Step 4-5: map the alias to provider/model; on errors fall back to the next one
    for provider, model in ALIASES[alias]:
        try:
            text, tokens = call_provider(provider, model, prompt)
        except TimeoutError as err:
            print(f"   {err}, falling back")
            continue
        SPENT[team] += tokens * 2 / 1e6
        LOG.append((team, provider, tokens))                   # Step 6: record usage per team
        CACHE[alias, prompt] = text
        return text
    return "503 all providers failed"

for prompt in ["summarize ticket 1", "summarize ticket 1", "summarize ticket 2"]:
    print(gateway("team-search", "smart", prompt))
print("usage log:", LOG)
