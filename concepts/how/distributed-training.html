How does distributed training (data parallel, FSDP) work?

In one lineEach GPU trains on different data; gradients are averaged across GPUs every step. FSDP also splits the model's weights and optimizer state across GPUs so bigger models fit.

Step by step
  1. The training data is split so each GPU gets a different mini-batch.
  2. Each GPU runs the forward and backward pass to compute gradients.
  3. An all-reduce averages the gradients across all GPUs.
  4. Every GPU applies the same update, so all copies stay identical.
  5. With FSDP or ZeRO, parameters, gradients and optimizer states are sharded across GPUs and gathered layer by layer when needed.
Key details
  • Plain data parallelism (DDP) needs the whole model plus optimizer state on each GPU.
  • Checkpoint regularly: long multi-node jobs will hit hardware failures.
