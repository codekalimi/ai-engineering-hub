How does PagedAttention work?

In one lineThe KV cache is stored in small fixed-size blocks, like operating-system memory pages, allocated only as a sequence grows, so almost no memory is wasted.

Step by step
  1. Older servers reserved one contiguous memory region per request, sized for the maximum possible length.
  2. Most of that reserved memory was never used, and the gaps fragmented memory.
  3. PagedAttention splits each sequence's KV cache into fixed-size blocks that can sit anywhere in memory.
  4. A block table maps each sequence's logical blocks to physical blocks, and new blocks are allocated only when needed.
  5. Requests with the same prefix can point to the same physical blocks.
Key details
  • Near-zero waste means bigger batches and higher throughput on the same GPU.
  • It's the core idea behind vLLM.
