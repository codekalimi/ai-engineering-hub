How does a RAG chain pass the question to both the retriever and the prompt?

In one lineA dict at the start of the chain becomes a RunnableParallel: the same question goes to the retriever and to a passthrough at the same time, producing {context, question} for the prompt.

Step by step
  1. The chain starts with a dict: {"context": retriever | format_docs, "question": RunnablePassthrough()}.
  2. LangChain turns the dict into a RunnableParallel, which sends the same input to every value.
  3. The retriever returns Documents, which format_docs joins into one text block; the passthrough returns the question as it is.
  4. The resulting dict fills the prompt's {context} and {question} variables.
  5. The rest is the normal prompt → model → parser sequence.
Key details
  • Forgetting format_docs puts a list of Document objects into the prompt.
  • RunnablePassthrough.assign(...) adds keys while keeping the input, useful for returning sources with the answer.

Use it

What you'd write at work

The classic LCEL RAG chain: a dict at the start sends the question to the retriever and keeps it for the prompt.

python
from langchain.chat_models import init_chat_model
from langchain.embeddings import init_embeddings
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough
from langchain_core.vectorstores import InMemoryVectorStore

retriever = InMemoryVectorStore.from_texts(
    ["LangGraph adds state and loops.", "LCEL composes runnables with the | operator.", "Paris is in France."],
    init_embeddings("openai:text-embedding-3-small")).as_retriever(search_kwargs={"k": 1})

def format_docs(docs):
    return "\n".join(d.page_content for d in docs)

prompt = ChatPromptTemplate.from_template("Use only this context:\n{context}\n\nQuestion: {question}")
chain = ({"context": retriever | format_docs, "question": RunnablePassthrough()}
         | prompt | init_chat_model("anthropic:claude-opus-5-5") | StrOutputParser())
print(chain.invoke("What does LCEL do?"))

✓ Ran with langchain 1.5.2, langchain-core 1.8.4 · with a scripted chat model in place of the API; a local embedding model (all-MiniLM-L6-v2) in place of the embedding API.

What it printed
LCEL composes runnables with the | operator.

Under the hood

What the library does for you, with its real classes

The same chain built explicitly: the dict is a RunnableParallel. RunnablePassthrough.assign keeps the documents so you can return citations.

python
from langchain.chat_models import init_chat_model
from langchain.embeddings import init_embeddings
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnableParallel, RunnablePassthrough
from langchain_core.vectorstores import InMemoryVectorStore

retriever = InMemoryVectorStore.from_texts(
    ["LangGraph adds state and loops.", "LCEL composes runnables with the | operator.", "Paris is in France."],
    init_embeddings("openai:text-embedding-3-small")).as_retriever(search_kwargs={"k": 1})
prompt = ChatPromptTemplate.from_template("Use only this context:\n{context}\n\nQuestion: {question}")
model = init_chat_model("anthropic:claude-opus-5-5")

# Steps 1-2: the dict IS a RunnableParallel - same input to every branch
setup = RunnableParallel(docs=retriever, question=RunnablePassthrough())
print("after the parallel step:", setup.invoke("What does LCEL do?"))

# Steps 3-5: format the docs into {context}, keep docs in the output for citations
answer = (lambda d: {"context": "\n".join(x.page_content for x in d["docs"]), "question": d["question"]}) | prompt | model | StrOutputParser()
chain = setup | RunnablePassthrough.assign(answer=answer)
out = chain.invoke("What does LCEL do?")
print("answer:", out["answer"], "| sources:", [d.page_content for d in out["docs"]])

✓ Ran with langchain 1.5.2, langchain-core 1.8.4 · with a scripted chat model in place of the API; a local embedding model (all-MiniLM-L6-v2) in place of the embedding API.

From scratch

The idea in plain Python, no libraries

A tiny version of the mechanism. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: nothing to install.

python3 · standard library only
# What {"context": retriever | format_docs, "question": RunnablePassthrough()} does underneath.
from concurrent.futures import ThreadPoolExecutor

DOCS = ["LangGraph adds state and loops.", "LCEL composes runnables with pipes.", "Paris is in France."]
def retriever(question):                     # returns documents sharing a word with the question
    q = set(question.lower().strip("?").split())
    return [d for d in DOCS if q & set(d.lower().strip(".").split())]
def format_docs(docs): return "\n".join(f"- {d}" for d in docs)
def passthrough(x): return x                 # RunnablePassthrough: the input, unchanged

def pipe(*fns):
    def run(x):
        for fn in fns:
            x = fn(x)
        return x
    return run

def parallel(branches):
    # Step 2: a dict becomes a RunnableParallel - the SAME input goes to every branch, concurrently
    def run(x):
        with ThreadPoolExecutor() as pool:
            futures = {key: pool.submit(fn, x) for key, fn in branches.items()}
            return {key: f.result() for key, f in futures.items()}
    return run

# Step 1 + 3: the context branch turns the question into text; the passthrough keeps the question
setup = parallel({"context": pipe(retriever, format_docs), "question": passthrough})
# Step 4: the dict fills the prompt's {context} and {question}
def prompt(d): return f"Use only this context:\n{d['context']}\n\nQuestion: {d['question']}"
# Step 5: then the usual model -> parser (stubbed)
def model(p): return f"(answer written from {p.count('- ')} context line)"

def show(label):
    def run(x):
        print(f"---- {label} ----\n{x}")
        return x
    return run

chain = pipe(setup, show("after the dict step"), prompt, show("prompt"), model)
print("answer:", chain("What does LCEL compose?"))

✓ Ran with plain Python 3.9+.
