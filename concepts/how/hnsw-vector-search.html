How does a vector database find nearest neighbours fast (HNSW)?

In one lineInstead of comparing the query with every vector, it walks a layered graph of neighbour links: long jumps on sparse upper layers, then finer steps on denser lower layers.

Step by step
  1. When a vector is inserted, it's linked to its nearest neighbours; a few vectors are also placed on higher, sparser layers.
  2. A search starts at an entry point on the top layer and keeps moving to whichever neighbour is closer to the query.
  3. When no neighbour is closer, it drops to the next layer and continues from that point.
  4. On the bottom layer, it explores a list of candidates (size ef) and returns the best k.
Key details
  • It's approximate: very fast, with recall usually 95–99%+, tunable through the M and ef parameters.
  • Exact brute-force search is fine up to tens of thousands of vectors.
  • Other index types: IVF (cluster first, then search nearby clusters), often combined with product quantization to compress vectors.

See it run

A tiny from-scratch version of what really happens. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: plain Python, nothing to install.

python3 · standard library only
# A small HNSW-style search: a sparse top layer for long jumps, a dense bottom layer for precision.
import math, random
random.seed(7)

points = [(random.uniform(0, 100), random.uniform(0, 100)) for _ in range(400)]
query = (73.0, 21.0)

# Step 1 (insert): link every point to its nearest neighbours; a few points are also promoted
# to an upper layer. (Real HNSW builds this incrementally as vectors arrive.)
def link(ids, m):
    return {i: sorted((j for j in ids if j != i), key=lambda j: math.dist(points[i], points[j]))[:m] for i in ids}
bottom_ids = list(range(len(points)))
top_ids = bottom_ids[::20]                     # ~5% of the points
layers = [link(top_ids, 4), link(bottom_ids, 8)]

memo = {}                                      # count how many distances we compute
def d(i):
    if i not in memo:
        memo[i] = math.dist(points[i], query)
    return memo[i]

# Steps 2-3: greedy walk on the top layer, then drop down and continue from there
cur = top_ids[0]
for name, graph in zip(["top", "bottom"], layers):
    improved = True
    while improved:
        improved = False
        for n in graph[cur]:
            if d(n) < d(cur):
                cur, improved = n, True
    print(f"{name:6} layer: closest so far = point {cur} at distance {d(cur):.1f}")

# Step 4: on the bottom layer, explore a candidate list of size ef and keep the best k
ef, k = 16, 3
cands, seen, frontier = [cur], {cur}, [cur]
while frontier:
    for n in layers[1][frontier.pop()]:
        if n not in seen:
            seen.add(n)
            cands = sorted(cands + [n], key=d)[:ef]
            if n in cands:
                frontier.append(n)

exact = sorted(bottom_ids, key=lambda i: math.dist(points[i], query))[:k]
print("HNSW top-3: ", sorted(cands, key=d)[:k], f"({len(memo)} distance checks)")
print("exact top-3:", exact, f"({len(points)} distance checks)")
