How does LangGraph execute a graph?

In one lineIt runs in steps: the active nodes read the state and return updates, reducers merge the updates, a checkpoint is saved, and edges decide which nodes run next, until END.

Step by step
  1. The input becomes the initial state, which has the schema you defined (e.g. MessagesState).
  2. The nodes scheduled for this step run (in parallel if there are several). Each reads the state and returns only the keys it changes.
  3. Reducers merge the updates into the state, e.g. add_messages appends instead of overwriting.
  4. If a checkpointer is attached, the new state is saved for this thread.
  5. Edges decide the next nodes: fixed edges always go to the same node; conditional edges call a function that looks at the state.
  6. This repeats until END is reached or the recursion limit is hit.
Key details
  • This step-based model (inspired by Pregel) is what makes checkpoints, interrupts and time travel possible.
  • The default recursion limit stops runaway loops; raise it deliberately when needed.

Use it

What you'd write at work

A graph you build yourself: state, nodes, a conditional edge. This is the agent loop as an explicit graph.

python
from langchain.chat_models import init_chat_model
from langchain.tools import tool
from langgraph.graph import START, MessagesState, StateGraph
from langgraph.prebuilt import ToolNode, tools_condition

@tool
def search(q: str) -> str:
    """Search the docs."""
    return "LangGraph is a runtime for stateful, multi-step agent graphs."

model = init_chat_model("anthropic:claude-opus-5-5").bind_tools([search])

graph = StateGraph(MessagesState)
graph.add_node("agent", lambda state: {"messages": [model.invoke(state["messages"])]})
graph.add_node("tools", ToolNode([search]))
graph.add_edge(START, "agent")
graph.add_conditional_edges("agent", tools_condition)     # tools if it asked for one, else END
graph.add_edge("tools", "agent")
app = graph.compile()

result = app.invoke({"messages": [("user", "What is LangGraph?")]})
print(result["messages"][-1].content)

✓ Ran with langchain 1.5.2, langgraph 1.2.24 · with a scripted chat model in place of the API.

What it printed
LangGraph runs your nodes in steps over shared state.

Under the hood

What the library does for you, with its real classes

Watching the engine run that graph step by step: which nodes run in each step, and what each returned.

python
from langchain.chat_models import init_chat_model
from langchain.tools import tool
from langgraph.graph import START, MessagesState, StateGraph
from langgraph.prebuilt import ToolNode, tools_condition

@tool
def search(q: str) -> str:
    """Search the docs."""
    return "LangGraph is a runtime for stateful, multi-step agent graphs."

model = init_chat_model("anthropic:claude-opus-5-5").bind_tools([search])
graph = StateGraph(MessagesState)
graph.add_node("agent", lambda state: {"messages": [model.invoke(state["messages"])]})
graph.add_node("tools", ToolNode([search]))
graph.add_edge(START, "agent")
graph.add_conditional_edges("agent", tools_condition)
graph.add_edge("tools", "agent")
app = graph.compile()

for e in app.get_graph().edges:                               # the structure you defined
    print(f"edge {e.source} -> {e.target}" + ("  (conditional)" if e.conditional else ""))
for event in app.stream({"messages": [("user", "What is LangGraph?")]}, stream_mode="debug"):
    if event["type"] == "task_result":                      # Steps 2-5, one line per node run
        update = dict(event["payload"]["result"])
        msg = update["messages"][-1]
        print(f"step {event['step']}: {event['payload']['name']:5} -> {msg.type}: {getattr(msg, 'tool_calls', None) or msg.content}")

✓ Ran with langchain 1.5.2, langgraph 1.2.24 · with a scripted chat model in place of the API.

From scratch

The idea in plain Python, no libraries

A tiny version of the mechanism. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: nothing to install.

python3 · standard library only
# A mini LangGraph engine: state + nodes + reducers + edges + a step loop.
import operator

REDUCERS = {"messages": operator.add}             # 'messages' appends; other keys overwrite

def merge(state, update):
    # Step 3: reducers merge each node's update into the state
    for k, v in update.items():
        state[k] = REDUCERS[k](state.get(k, []), v) if k in REDUCERS else v
    return state

def agent(state):                                 # pretend LLM: ask for a tool once, then answer
    if not any(m.startswith("tool:") for m in state["messages"]):
        return {"messages": ["ai: call search('langgraph')"]}
    return {"messages": ["ai: LangGraph runs nodes in steps."]}

def tools(state):
    return {"messages": ["tool: 'LangGraph is a graph runtime'"]}

NODES = {"agent": agent, "tools": tools}
EDGES = {"tools": "agent"}                        # fixed edge: tools -> agent
def route_after_agent(state):                     # conditional edge: a function picks the next node
    return "tools" if "call" in state["messages"][-1] else "END"
CONDITIONAL = {"agent": route_after_agent}

checkpoints = []
def invoke(inp, recursion_limit=10):
    state, next_nodes = merge({}, inp), ["agent"]          # Step 1: input -> initial state
    for step in range(1, recursion_limit + 1):
        if not next_nodes:
            return state
        updates = [(n, NODES[n](dict(state))) for n in next_nodes]   # Step 2: run scheduled nodes
        for n, u in updates:
            state = merge(state, u)
        checkpoints.append({"step": step, "state": dict(state)})      # Step 4: checkpoint
        # Step 5: edges decide the next nodes
        nxt = [CONDITIONAL[n](state) if n in CONDITIONAL else EDGES[n] for n, _ in updates]
        print(f"step {step}: ran {[n for n, _ in updates]} -> next {nxt}")
        next_nodes = [n for n in nxt if n != "END"]
    raise RuntimeError("recursion limit reached")           # Step 6

final = invoke({"messages": ["user: what is langgraph?"]})
print("messages:", final["messages"])
print("checkpoints saved:", len(checkpoints))

✓ Ran with plain Python 3.9+.

What it prints

step 2: ran ['tools'] -> next ['agent']
step 3: ran ['agent'] -> next ['END']
messages: ['user: what is langgraph?', "ai: call search('langgraph')", "tool: 'LangGraph is a graph runtime'", 'ai: LangGraph runs nodes in steps.']
checkpoints saved: 3
Watch it in a real system
  • for chunk in graph.stream(inputs, stream_mode="debug"): print(chunk) prints every task start and result, step by step: the engine below, in real life.
  • stream_mode="updates" shows each node’s partial update; stream_mode="values" shows the full state after every step.
  • Hit the limit on purpose with graph.invoke(inputs, {"recursion_limit": 3}) to see a GraphRecursionError.
