How does streaming reach the browser (SSE)?

In one lineThe server calls the model in streaming mode and forwards each chunk to the browser as a Server-Sent Event, so text appears as it's generated.

Step by step
  1. The browser opens a long-lived HTTP connection (EventSource or fetch with a stream reader).
  2. Your API calls the model with streaming enabled (astream in LangChain).
  3. Each chunk from the model is forwarded immediately as a "data:" line.
  4. The browser appends each chunk to the UI as it arrives.
  5. At the end, the server logs the full answer and usage, then sends a done event.
Key details
  • Cancel the upstream model call if the browser disconnects, so you don't pay for unread tokens.
  • Proxies can buffer responses; disable buffering (e.g. X-Accel-Buffering: no on nginx).
  • For agents, astream_events can stream progress such as "calling a tool…" as well as tokens.

Use it

What you'd write at work

A FastAPI endpoint that streams model tokens to the browser as Server-Sent Events.

python
import json
from fastapi import FastAPI
from fastapi.responses import StreamingResponse
from fastapi.testclient import TestClient
from langchain.chat_models import init_chat_model

app = FastAPI()
model = init_chat_model("anthropic:claude-opus-5-5")

@app.get("/chat/stream")
async def chat_stream(q: str):
    async def events():
        async for chunk in model.astream(q):                       # Step 2: stream from the model
            if chunk.content:
                yield f"data: {json.dumps({'delta': chunk.content})}\n\n"   # Step 3: forward each chunk
        yield "event: done\ndata: {}\n\n"                          # Step 5
    return StreamingResponse(events(), media_type="text/event-stream")

# Step 1 + 4: a client reading the stream (in a browser: EventSource or fetch with a reader)
with TestClient(app).stream("GET", "/chat/stream", params={"q": "why stream?"}) as response:
    print(response.headers["content-type"])
    for line in response.iter_lines():
        if line:
            print(line)

✓ Ran with langchain 1.5.2 · with a scripted chat model in place of the API.

Under the hood

What the library does for you, with its real classes

What astream builds on: every runnable emits start/stream/end events, and chunks are merged with +.

python
import asyncio
from langchain.chat_models import init_chat_model
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate

chain = ChatPromptTemplate.from_template("{q}") | init_chat_model("anthropic:claude-opus-5-5") | StrOutputParser()

async def main():
    async for ev in chain.astream_events({"q": "hi"}, version="v2"):
        data = ev["data"].get("chunk")
        print(f"{ev['event']:24} {ev['name']:22} {getattr(data, 'content', data) if data is not None else ''!r}")

asyncio.run(main())

# chunks are AIMessageChunk objects; + merges them into the full message
model = init_chat_model("anthropic:claude-opus-5-5")
full = None
for chunk in model.stream("hi"):
    full = chunk if full is None else full + chunk
print(type(full).__name__, repr(full.content))

✓ Ran with langchain 1.5.2, langchain-core 1.8.4 · with a scripted chat model in place of the API.

From scratch

The idea in plain Python, no libraries

A tiny version of the mechanism. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: nothing to install.

python3 · standard library only
# Server-Sent Events: the raw HTTP response body is plain text, one "data:" line per event.
import json

def fake_model_stream(prompt):
    # Step 2: the model is called with streaming on and yields tokens as it produces them
    yield from ["Stream", "ing ", "shows ", "tokens ", "early."]

def sse_endpoint(prompt):
    # Response header: Content-Type: text/event-stream
    full = []
    for chunk in fake_model_stream(prompt):
        full.append(chunk)
        # Step 3: forward each chunk immediately; a blank line ends each event
        yield f"data: {json.dumps({'delta': chunk})}\n\n"
    # Step 5: log the full answer and usage, then send a final 'done' event
    yield f"event: done\ndata: {json.dumps({'chars': len(''.join(full))})}\n\n"

# Step 1: the browser keeps the connection open (EventSource or fetch with a stream reader)
ui = ""
for n, raw in enumerate(sse_endpoint("hi"), 1):
    print(f"event {n} on the wire: {raw!r}")
    # Step 4: the browser parses each event and appends the text to the UI
    for line in raw.splitlines():
        if line.startswith("data:") and "delta" in line:
            ui += json.loads(line[len("data:"):])["delta"]
print("UI now shows:", ui)

Watch it in a real system
  • curl -N http://localhost:8000/chat/stream (the -N turns off buffering) prints the raw data: lines as they arrive.
  • Browser DevTools, Network tab: click the request and open the EventStream tab to see each event with its arrival time.
  • LangChain: async for ev in chain.astream_events(inputs, version="v2"): print(ev["event"], ev["name"]) shows every token event before you forward it.
