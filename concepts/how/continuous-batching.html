How does continuous batching work?

In one lineInstead of waiting for a whole batch to finish, the server re-forms the batch at every token step: finished requests leave and waiting ones join immediately.

Step by step
  1. LLM requests vary hugely in output length, from a few tokens to thousands.
  2. With static batching, the GPU waits for the longest request while finished slots stay empty.
  3. Continuous batching schedules at the level of single decode steps.
  4. As soon as a request finishes, a waiting request takes its place in the next step.
Key details
  • Typically gives several times higher throughput than static batching.
  • Standard in vLLM, TGI, TensorRT-LLM and SGLang.
