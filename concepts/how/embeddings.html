How do embeddings and semantic search work?

In one lineAn embedding model turns text into a vector so that similar meanings land close together. Search embeds the query and returns the nearest document vectors.

Step by step
  1. An embedding model (a transformer trained for this purpose) reads a text and outputs a fixed-length vector.
  2. It's trained so related texts, such as a question and its answer, get similar vectors (contrastive training).
  3. Documents are embedded once and stored.
  4. A query is embedded with the same model, and the documents with the highest cosine similarity are returned.
Key details
  • Never mix vectors from different embedding models.
  • Embeddings capture meaning but blur exact identifiers, which is why hybrid search exists.
  • More dimensions can mean better accuracy but more storage; some models let you shorten vectors.

Use it

What you'd write at work

Embed once, store, then search by meaning. In production the store is pgvector, Qdrant, Pinecone and so on: same interface.

python
from langchain.embeddings import init_embeddings
from langchain_core.vectorstores import InMemoryVectorStore

embeddings = init_embeddings("openai:text-embedding-3-small")
store = InMemoryVectorStore(embeddings)
store.add_texts(["Refunds are processed within 5 working days.",
                 "Reset your password from the account settings page.",
                 "We ship to 40 countries worldwide."])

for doc, score in store.similarity_search_with_score("how long does a refund take", k=2):
    print(f"{score:.2f}  {doc.page_content}")

✓ Ran with langchain 1.5.2, langchain-core 1.8.4 · with a local embedding model (all-MiniLM-L6-v2) in place of the embedding API.

What it printed
0.78  Refunds are processed within 5 working days.
0.01  Reset your password from the account settings page.

Under the hood

What the library does for you, with its real classes

What the store does on add and on search: embed the texts, embed the query with the same model, rank by cosine similarity.

python
import math
from langchain.embeddings import init_embeddings

embeddings = init_embeddings("openai:text-embedding-3-small")
texts = ["Refunds are processed within 5 working days.",
         "Reset your password from the account settings page.",
         "We ship to 40 countries worldwide."]

vectors = embeddings.embed_documents(texts)        # Steps 1 + 3: one vector per text, stored
query = embeddings.embed_query("how long does a refund take")   # Step 4: same model for the query
print(f"{len(vectors)} vectors of {len(query)} numbers each")

def cosine(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    return dot / (math.sqrt(sum(x * x for x in a)) * math.sqrt(sum(y * y for y in b)))

for text, vec in sorted(zip(texts, vectors), key=lambda tv: -cosine(query, tv[1])):
    print(f"{cosine(query, vec):.2f}  {text}")

✓ Ran with langchain 1.5.2 · with a local embedding model (all-MiniLM-L6-v2) in place of the embedding API.

What it printed
3 vectors of 384 numbers each
0.78  Refunds are processed within 5 working days.
0.01  Reset your password from the account settings page.
-0.07  We ship to 40 countries worldwide.

From scratch

The idea in plain Python, no libraries

A tiny version of the mechanism. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: nothing to install.

python3 · standard library only
# A real embedding model is a trained transformer. Here each word has a hand-made vector over
# 3 "meaning" dimensions [pets, money, weather]; a text's vector is the average of its words.
import math

WORDS = {"dog": [1, 0, 0], "puppy": [.9, 0, .1], "cat": [.9, 0, 0], "vet": [.8, .2, 0],
         "bank": [0, 1, 0], "loan": [0, .9, 0], "interest": [0, .8, .1], "rate": [0, .6, .2],
         "rain": [0, 0, 1], "storm": [0, .1, .9], "forecast": [0, .1, .8]}

def embed(text):
    # Step 1: text -> a fixed-length vector
    vecs = [WORDS[w] for w in text.lower().split() if w in WORDS]
    return [sum(c) / len(vecs) for c in zip(*vecs)]

def cosine(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    return dot / (math.sqrt(sum(x * x for x in a)) * math.sqrt(sum(y * y for y in b)))

# Step 3: documents are embedded once and stored
docs = ["Take your puppy to the vet", "Bank loan interest rate rises", "Storm and rain forecast"]
index = [(d, embed(d)) for d in docs]

# Step 4: the query is embedded with the same model; rank by cosine similarity
for query in ["my dog is sick", "what will the rate be on my loan"]:
    q = embed(query)
    print(f"query: {query!r}")
    for d, v in sorted(index, key=lambda dv: cosine(q, dv[1]), reverse=True):
        print(f"   {cosine(q, v):.2f}  {d}")

✓ Ran with plain Python 3.9+.
