How does semantic caching work?

In one lineQuestions are embedded; if a new question is close enough in meaning to one already answered, the stored answer is returned without calling the LLM.

Step by step
  1. Each incoming question is embedded.
  2. The cache is searched for previously answered questions with similar meaning.
  3. If the best match is above a similarity threshold, its stored answer is returned.
  4. Otherwise the LLM is called, and the new question and answer are added to the cache.
Key details
  • Great for FAQ-style traffic; risky when answers depend on the user or change over time.
  • Scope the cache per tenant or user where answers are personal.
  • Tune the threshold with real examples; too loose returns wrong answers.

Use it

What you'd write at work

A semantic cache in front of the model: a vector store of past questions, reused above a similarity threshold. Real embeddings, so you can see a correct hit and a dangerous one.

python
from langchain.chat_models import init_chat_model
from langchain.embeddings import init_embeddings
from langchain_core.vectorstores import InMemoryVectorStore

model = init_chat_model("anthropic:claude-opus-5-5")
cache = InMemoryVectorStore(init_embeddings("openai:text-embedding-3-small"))
THRESHOLD = 0.7

def ask(question):
    hits = cache.similarity_search_with_score(question, k=1)
    if hits and hits[0][1] >= THRESHOLD:
        doc, score = hits[0]
        print(f"HIT  {score:.2f} {question!r} reuses {doc.page_content!r}")
        return doc.metadata["answer"]
    answer = model.invoke(question).content
    cache.add_texts([question], metadatas=[{"answer": answer}])
    print(f"MISS {hits[0][1] if hits else 0:.2f} {question!r} -> called the model")
    return answer

for q in ["How do I get a refund?", "How can I get my money back?", "When will my order ship?",
          "Cancel my subscription", "Do not cancel my subscription"]:
    ask(q)

✓ Ran with langchain 1.5.2, langchain-core 1.8.4 · with a scripted chat model in place of the API; a local embedding model (all-MiniLM-L6-v2) in place of the embedding API.

Under the hood

What the library does for you, with its real classes

Choosing the threshold: the real similarity scores between question pairs that should and should not share an answer.

python
import numpy as np
from langchain.embeddings import init_embeddings

emb = init_embeddings("openai:text-embedding-3-small")
pairs = [  # (question A, question B, should they share an answer?)
    ("How do I get a refund?", "How can I get my money back?", True),
    ("When will my order ship?", "How long until my parcel is dispatched?", True),
    ("Cancel my subscription", "Do not cancel my subscription", False),
    ("Reset my password", "Reset my router", False),
]
scores = []
for a, b, same in pairs:
    va, vb = np.array(emb.embed_query(a)), np.array(emb.embed_query(b))
    s = float(va @ vb / (np.linalg.norm(va) * np.linalg.norm(vb)))     # Steps 1-2: cosine similarity
    scores.append((s, same))
    print(f"{s:.2f}  {'same answer' if same else 'DIFFERENT':11}  {a!r} vs {b!r}")

for t in (0.7, 0.8, 0.9):                                              # Step 3: the threshold decides
    good = sum(s >= t for s, same in scores if same)
    bad = sum(s >= t for s, same in scores if not same)
    print(f"threshold {t}: {good}/2 correct hits, {bad} wrong hits")

✓ Ran with numpy 2.5.5, langchain 1.5.2 · with a local embedding model (all-MiniLM-L6-v2) in place of the embedding API.

From scratch

The idea in plain Python, no libraries

A tiny version of the mechanism. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: nothing to install.

python3 · standard library only
import math
# Toy embedding: count words after mapping synonyms to the same meaning (a real system uses a model).
MEANING = {"refund": "refund", "money": "refund", "back": "refund", "ship": "ship", "arrive": "ship",
           "delivery": "ship", "cancel": "cancel", "order": "order", "subscription": "sub"}

def embed(text):
    v = {}
    for w in text.lower().strip("?").split():
        if w in MEANING:
            v[MEANING[w]] = v.get(MEANING[w], 0) + 1
    return v

def cosine(a, b):
    dot = sum(a[k] * b.get(k, 0) for k in a)
    na, nb = math.sqrt(sum(x * x for x in a.values())), math.sqrt(sum(x * x for x in b.values()))
    return dot / (na * nb) if na and nb else 0.0

cache, THRESHOLD, llm_calls = [], 0.9, 0
def ask(question):
    global llm_calls
    v = embed(question)                                                  # Step 1
    best = max(cache, key=lambda e: cosine(v, e[0]), default=None)       # Step 2
    score = cosine(v, best[0]) if best else 0.0
    if score >= THRESHOLD:                                               # Step 3
        print(f"HIT  {score:.2f} {question!r} -> reuse the answer to {best[1]!r}")
        return best[2]
    llm_calls += 1                                                       # Step 4
    cache.append((v, question, f"answer #{llm_calls}"))
    print(f"MISS {score:.2f} {question!r} -> called the LLM")

for q in ["How do I get a refund?", "How can I get my money back?", "When will my order arrive?",
          "Cancel my subscription", "Do not cancel my subscription"]:
    ask(q)
print("the last hit is WRONG: same words, opposite meaning - test thresholds on real traffic")

✓ Ran with plain Python 3.9+.

Watch it in a real system
  • Log the best similarity score for every lookup, hit or miss; plot them to pick a threshold instead of guessing.
  • Review a sample of cache hits by hand: look for near-miss pairs with opposite meaning ("cancel" vs "do not cancel").
  • Libraries such as GPTCache and Redis-based semantic caches (also integrated in LangChain) expose the threshold and the stored question for each hit.
