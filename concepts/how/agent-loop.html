How does an agent loop work?

In one lineAn agent is a loop: the model decides whether to call a tool; if it does, the tool runs and the result goes back to the model; when it stops calling tools, its reply is the answer.

Step by step
  1. The agent starts with the task, the system prompt and the available tools.
  2. Each turn, the model either requests tool calls or writes a final answer.
  3. If it requests tools, they run and their results are appended to the conversation.
  4. The model is called again with the updated conversation.
  5. When it replies without a tool call, that reply is the final answer.
Key details
  • Always set a step limit (LangGraph's recursion_limit) plus timeouts and cost budgets.
  • Require human approval for irreversible actions.
  • Return tool errors as text so the model can recover instead of retrying blindly.

Use it

What you'd write at work

create_agent builds the loop for you (on LangGraph). You give it a model, tools and a prompt.

python
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.tools import tool

@tool
def search_flights(src: str, dst: str) -> list:
    """Find flights between two airport codes."""
    return [{"flight": "AI-101", "price": 5400}, {"flight": "6E-22", "price": 4100}]

@tool
def book(flight: str) -> str:
    """Book a flight by its number."""
    return f"booked {flight}, ref XK42"

agent = create_agent(init_chat_model("anthropic:claude-opus-5-5"), [search_flights, book],
                     system_prompt="You book travel. Always pick the cheapest option.")
result = agent.invoke({"messages": [("user", "Book me the cheapest flight from Pune to Delhi")]},
                      {"recursion_limit": 10})                     # the step limit
for m in result["messages"]:
    print(f"{m.type:5}", m.tool_calls if getattr(m, "tool_calls", None) else m.content)

✓ Ran with langchain 1.5.2 · with a scripted chat model in place of the API.

Under the hood

What the library does for you, with its real classes

The loop create_agent runs, written out with the real message classes. Each comment names the part of create_agent it replaces.

python
from langchain.chat_models import init_chat_model
from langchain.messages import HumanMessage, SystemMessage, ToolMessage
from langchain.tools import tool

@tool
def search_flights(src: str, dst: str) -> list:
    """Find flights between two airport codes."""
    return [{"flight": "AI-101", "price": 5400}, {"flight": "6E-22", "price": 4100}]

@tool
def book(flight: str) -> str:
    """Book a flight by its number."""
    return f"booked {flight}, ref XK42"

tools = {t.name: t for t in [search_flights, book]}
llm_with_tools = init_chat_model("anthropic:claude-opus-5-5").bind_tools(list(tools.values()))

def run_agent(question, max_steps=10):            # <- what create_agent() builds for you
    messages = [SystemMessage("You book travel. Always pick the cheapest option."),   # Step 1
                HumanMessage(question)]
    for step in range(1, max_steps + 1):          # <- recursion_limit
        ai = llm_with_tools.invoke(messages)      # Step 2: one model call ("model" node)
        messages.append(ai)
        if not ai.tool_calls:                     # Step 5: no tool call -> done (edge to END)
            return ai.content
        for call in ai.tool_calls:                # Step 3: the "tools" node (ToolNode)
            try:
                result = tools[call["name"]].invoke(call["args"])
            except Exception as err:
                result = f"Error: {err}"          # errors go back as text, the model can recover
            messages.append(ToolMessage(str(result), tool_call_id=call["id"]))
            print(f"step {step}: {call['name']}({call['args']}) -> {result}")
        # Step 4: loop - call the model again with the longer conversation
    raise RuntimeError("step limit reached")

print("final:", run_agent("Book me the cheapest flight from Pune to Delhi"))

✓ Ran with langchain 1.5.2 · with a scripted chat model in place of the API.

What it printed
step 1: search_flights({'src': 'PNQ', 'dst': 'DEL'}) -> [{'flight': 'AI-101', 'price': 5400}, {'flight': '6E-22', 'price': 4100}]
step 2: book({'flight': '6E-22'}) -> booked 6E-22, ref XK42
final: Booked the cheapest flight, 6E-22 for 4100 (ref XK42).

From scratch

The idea in plain Python, no libraries

A tiny version of the mechanism. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: nothing to install.

python3 · standard library only
import json

def search_flights(src, dst):
    return [{"flight": "AI-101", "price": 5400}, {"flight": "6E-22", "price": 4100}]
def book(flight):
    return f"booked {flight}, ref XK42"
TOOLS = {"search_flights": search_flights, "book": book}

def llm(messages):
    # a scripted stand-in for the model: it reads the conversation and decides the next move
    results = [m for m in messages if m["role"] == "tool"]
    if not results:
        return {"tool_calls": [{"id": "c1", "name": "search_flights", "args": {"src": "PNQ", "dst": "DEL"}}]}
    if len(results) == 1:
        cheapest = min(json.loads(results[0]["content"]), key=lambda f: f["price"])
        return {"tool_calls": [{"id": "c2", "name": "book", "args": {"flight": cheapest["flight"]}}]}
    return {"content": "Booked the cheapest flight, 6E-22 (ref XK42)."}

# Step 1: start with the task (plus, in real life, a system prompt and the tool schemas)
messages = [{"role": "user", "content": "Book me the cheapest flight from Pune to Delhi"}]
MAX_STEPS = 5                                    # always cap the loop
for step in range(1, MAX_STEPS + 1):
    # Step 2: each turn the model either requests tools or answers
    reply = llm(messages)
    messages.append({"role": "assistant", **reply})
    if "tool_calls" not in reply:
        # Step 5: no tool call -> this reply is the final answer
        print(f"step {step}: FINAL -> {reply['content']}")
        break
    for call in reply["tool_calls"]:
        # Step 3: run the tool and append its result (errors go back as text, not exceptions)
        try:
            result = TOOLS[call["name"]](**call["args"])
        except Exception as err:
            result = f"error: {err}"
        messages.append({"role": "tool", "tool_call_id": call["id"], "content": json.dumps(result)})
        print(f"step {step}: {call['name']}({call['args']}) -> {result}")
    # Step 4: loop - the model is called again with the longer conversation
else:
    print("stopped: step limit reached")
print(f"{len(messages)} messages in the conversation after {step} LLM calls")

✓ Ran with plain Python 3.9+.

What it prints

step 2: book({'flight': '6E-22'}) -> booked 6E-22, ref XK42
step 3: FINAL -> Booked the cheapest flight, 6E-22 (ref XK42).

Watch it in a real system
  • LangChain/LangGraph agents: result = agent.invoke({"messages": [("user", "...")]}), then for m in result["messages"]: m.pretty_print() shows every turn: AI tool calls, tool results, final answer.
  • Watch it live: for step in agent.stream(inputs, stream_mode="updates"): print(step) prints one update per loop iteration.
  • LangSmith (set LANGSMITH_TRACING=true) shows each loop turn as a child run with the exact prompt, tool arguments, timings and tokens.
