How does an LCEL chain (prompt | model | parser) execute?

In one lineThe | operator only builds a RunnableSequence object. When you call invoke, it runs each step in order, passing each output into the next step.

Step by step
  1. Every component implements the Runnable interface: invoke, batch, stream and their async versions.
  2. a | b calls a.__or__(b), which returns a RunnableSequence. A dict becomes a RunnableParallel and a function becomes a RunnableLambda.
  3. invoke loops over the steps, feeding each output into the next step's input.
  4. stream passes chunks through every step that supports streaming, so tokens reach you as they're generated.
  5. batch runs many inputs in parallel with a thread pool (or asyncio for abatch).
Key details
  • The config (callbacks, tags, run name) is passed down to every inner step, which is how tracing sees each one.
  • A plain function in the middle of a chain stops streaming at that point unless it's a generator.
chain = prompt | model | StrOutputParser()

def invoke(x):
    for step in [prompt, model, parser]:
        x = step.invoke(x)
    return x
Behind the scenes

See it run

A tiny from-scratch version of what really happens. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: plain Python, nothing to install.

python3 · standard library only
# A from-scratch version of LangChain's Runnable and the | operator.
from concurrent.futures import ThreadPoolExecutor
VERBOSE = True

class Runnable:
    # Step 1: one interface for everything: invoke, batch, stream
    def invoke(self, x):
        raise NotImplementedError
    def __or__(self, other):                       # Step 2: a | b -> RunnableSequence
        return RunnableSequence(self, coerce(other))
    def batch(self, xs):                           # Step 5: many inputs in parallel (thread pool)
        with ThreadPoolExecutor() as pool:
            return list(pool.map(self.invoke, xs))
    def stream(self, x):                           # default: one chunk = the whole result
        yield self.invoke(x)

class RunnableLambda(Runnable):
    def __init__(self, fn, name):
        self.fn, self.name = fn, name
    def invoke(self, x):
        out = self.fn(x)
        if VERBOSE:
            print(f"   {self.name}: {x!r} -> {out!r}")
        return out

class RunnableSequence(Runnable):
    def __init__(self, *steps):
        self.steps = steps
    def __or__(self, other):                       # (a | b) | c flattens into one sequence
        return RunnableSequence(*self.steps, coerce(other))
    def invoke(self, x):                           # Step 3: feed each output into the next step
        for step in self.steps:
            x = step.invoke(x)
        return x
    def stream(self, x):                           # Step 4: run the earlier steps, stream the last
        for step in self.steps[:-1]:
            x = step.invoke(x)
        yield from self.steps[-1].stream(x)

def coerce(obj):                                   # plain functions become runnables
    return obj if isinstance(obj, Runnable) else RunnableLambda(obj, obj.__name__)

class FakeChatModel(Runnable):
    def stream(self, prompt):                      # a chat model streams token by token
        yield from ["Paris", " is", " the", " capital", "."]
    def invoke(self, prompt):
        out = "".join(self.stream(prompt))
        if VERBOSE:
            print(f"   model: {prompt!r} -> {out!r}")
        return out

prompt = RunnableLambda(lambda d: f"What is the capital of {d['country']}?", "prompt")
def parser(text): return text.strip().upper()

chain = prompt | FakeChatModel() | parser
print("chain is a", type(chain).__name__, "with", len(chain.steps), "steps")
print("invoke:")
print(" =>", chain.invoke({"country": "France"}))
print("stream:", list((prompt | FakeChatModel()).stream({"country": "France"})))
VERBOSE = False                                    # threads would interleave the prints
print("batch:", chain.batch([{"country": "France"}, {"country": "Japan"}]))
