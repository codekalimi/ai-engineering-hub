How does sampling (temperature, top-k, top-p) work?

In one lineScores are divided by the temperature, turned into probabilities, cut down to the most likely tokens, and then one token is drawn at random.

Step by step
  1. Logits are raw scores for every token in the vocabulary.
  2. Dividing by a temperature below 1 exaggerates the differences (more focused); above 1 flattens them (more random). Temperature 0 means always taking the top token (greedy).
  3. Softmax converts the scores into probabilities that add up to 1.
  4. Top-k keeps only the k most likely tokens; top-p keeps the smallest set whose probabilities add up to p.
  5. One token is drawn at random from what's left, weighted by probability.
Key details
  • Extraction and classification: temperature around 0. Creative writing: around 0.7–1.
  • Tune temperature or top-p, rarely both.
  • Even greedy decoding can vary slightly between runs because of batching and floating-point order on the server.
import numpy as np

def sample(logits, temperature=0.7, top_p=0.9):
    if temperature == 0:
        return int(np.argmax(logits))
    p = np.exp((logits - logits.max()) / temperature)
    p /= p.sum()
    order = np.argsort(-p)
    keep = order[: np.searchsorted(np.cumsum(p[order]), top_p) + 1]
    return int(np.random.choice(keep, p=p[keep] / p[keep].sum()))
