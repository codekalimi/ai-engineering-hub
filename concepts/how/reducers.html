How do reducers merge state updates in LangGraph?

In one lineEach state key can have a reducer that decides how a node's update combines with the current value. Without one, the new value overwrites the old.

Step by step
  1. The state schema can annotate a key with a reducer, e.g. messages: Annotated[list, add_messages].
  2. When a node returns an update, LangGraph calls the reducer with the current value and the update.
  3. add_messages appends new messages; a message with an existing id replaces that message instead.
  4. Keys without a reducer simply take the new value.
Key details
  • Reducers matter most when parallel nodes update the same key in one step.
  • Return only changed keys from a node; returning the whole messages list again can duplicate messages.
from typing import Annotated, TypedDict
from operator import add
from langgraph.graph.message import add_messages

class State(TypedDict):
    messages: Annotated[list, add_messages]   # append / update by id
    sources: Annotated[list, add]             # concatenate lists
    status: str                               # overwrite
