How do callbacks and tracing (LangSmith) work?

In one lineEvery Runnable reports events (start, token, end, error) with a run ID and its parent's ID; tracers collect them into a tree showing each step's input, output, time and tokens.

Step by step
  1. When a chain, model, tool or retriever starts, it gets a run ID and records its parent run's ID.
  2. It emits events such as on_chain_start, on_llm_new_token, on_tool_end and errors.
  3. Callback handlers attached through config receive these events.
  4. A tracer such as LangSmith (enabled with environment variables) sends them to a server.
  5. The parent IDs rebuild the whole run as a tree you can inspect step by step.
Key details
  • It's the fastest way to debug a wrong answer: open the trace and see exactly what each step received.
  • Traces contain user data; mask sensitive fields where needed.

Use it

What you'd write at work

A callback handler sees every model, tool and chain start and end. LangSmith is the same mechanism, switched on with environment variables.

python
from langchain.chat_models import init_chat_model
from langchain_core.callbacks import BaseCallbackHandler
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate

class Spy(BaseCallbackHandler):
    def on_chat_model_start(self, serialized, messages, **kw):
        print("MODEL IN: ", [m.content for m in messages[0]])
    def on_llm_end(self, response, **kw):
        print("MODEL OUT:", response.generations[0][0].text)
    def on_chain_end(self, outputs, *, parent_run_id=None, **kw):
        if parent_run_id is None:                      # only the outermost run, not every step
            print("CHAIN END:", repr(outputs))

chain = ChatPromptTemplate.from_template("Answer briefly: {q}") | init_chat_model("anthropic:claude-opus-5-5") | StrOutputParser()
chain.invoke({"q": "How long do refunds take?"}, config={"callbacks": [Spy()]})
# For LangSmith instead: export LANGSMITH_TRACING=true LANGSMITH_API_KEY=...  (no code changes)

✓ Ran with langchain 1.5.2, langchain-core 1.8.4 · with a scripted chat model in place of the API.

What it printed
MODEL IN:  ['Answer briefly: How long do refunds take?']
MODEL OUT: Refunds take 5 days.
CHAIN END: 'Refunds take 5 days.'

Under the hood

What the library does for you, with its real classes

How a tracer rebuilds the run tree: every event carries run_id and parent_run_id.

python
from langchain.chat_models import init_chat_model
from langchain_core.callbacks import BaseCallbackHandler
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate

class TreeTracer(BaseCallbackHandler):                 # what LangSmith's tracer does, minus the upload
    def __init__(self):
        self.runs = {}
    def _start(self, name, run_id, parent_run_id):
        self.runs[run_id] = {"name": name, "parent": parent_run_id}     # Step 1: id + parent
    def on_chain_start(self, serialized, inputs, *, run_id, parent_run_id=None, **kw):
        self._start(kw.get("name") or "chain", run_id, parent_run_id)
    def on_chat_model_start(self, serialized, messages, *, run_id, parent_run_id=None, **kw):
        self._start("chat_model", run_id, parent_run_id)

tracer = TreeTracer()
chain = ChatPromptTemplate.from_template("Answer briefly: {q}") | init_chat_model("anthropic:claude-opus-5-5") | StrOutputParser()
chain.invoke({"q": "How long do refunds take?"}, config={"callbacks": [tracer], "run_name": "refund_bot"})

def show(parent=None, depth=0):                        # Step 5: rebuild the tree from parent ids
    for run_id, r in tracer.runs.items():
        if r["parent"] == parent:
            print("  " * depth + "- " + r["name"])
            show(run_id, depth + 1)
show()

✓ Ran with langchain 1.5.2, langchain-core 1.8.4 · with a scripted chat model in place of the API.

What it printed
- refund_bot
  - ChatPromptTemplate
  - chat_model
  - StrOutputParser

From scratch

The idea in plain Python, no libraries

A tiny version of the mechanism. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: nothing to install.

python3 · standard library only
# Every run gets an id and a parent id; handlers receive start/end events.
import itertools
ids = itertools.count(1)

class PrintHandler:                      # like a BaseCallbackHandler with on_*_start / on_*_end
    def on_start(self, run):
        print(f"{'  ' * run['depth']}start {run['type']}:{run['name']} (run {run['id']}, parent {run['parent']})")
    def on_end(self, run, out):
        print(f"{'  ' * run['depth']}end   {run['name']} -> {out!r}")

class Tracer:                            # like LangSmith: collect the runs, rebuild the tree later
    def __init__(self):
        self.runs = []
    def on_start(self, run):
        self.runs.append(run)
    def on_end(self, run, out):
        run["output"] = out

def traced(kind, name):
    def wrap(fn):
        def inner(x, config, parent=None, depth=0):
            run = {"id": next(ids), "parent": parent, "type": kind, "name": name, "depth": depth}  # Step 1
            for h in config["callbacks"]:
                h.on_start(run)          # Step 2-3: events go to every attached handler
            out = fn(x, config, run["id"], depth + 1)
            for h in config["callbacks"]:
                h.on_end(run, out)
            return out
        return inner
    return wrap

@traced("retriever", "search_docs")
def retrieve(q, config, parent, depth):
    return ["doc about " + q]

@traced("llm", "chat_model")
def llm(docs, config, parent, depth):
    return "answer using " + docs[0]

@traced("chain", "rag_chain")
def rag(q, config, parent, depth):
    return llm(retrieve(q, config, parent, depth), config, parent, depth)

tracer = Tracer()
rag("refunds", {"callbacks": [PrintHandler(), tracer]})

# Step 4-5: a tracer sends the runs to a server; parent ids rebuild the tree
children = {}
for r in tracer.runs:
    children.setdefault(r["parent"], []).append(r)
def show(parent, indent=0):
    for r in children.get(parent, []):
        print("  " * indent + f"- {r['name']} ({r['type']})")
        show(r["id"], indent + 1)
print("trace tree:")
show(None)

✓ Ran with plain Python 3.9+.

What it prints
start chain:rag_chain (run 1, parent None)
  start retriever:search_docs (run 2, parent 1)
  end   search_docs -> ['doc about refunds']
  start llm:chat_model (run 3, parent 1)
  end   chat_model -> 'answer using doc about refunds'
end   rag_chain -> 'answer using doc about refunds'
trace tree:
