How does structured output (JSON mode, constrained decoding) work?

In one lineEither the model is trained to emit schema-shaped JSON (as in tool calling), or the server restricts which tokens may be chosen at each step so the output must match your schema.

How to read this diagram

Flow diagram: read left to right. Dashed loops show steps that repeat; ↓ joins rows that follow on from each other.

Step by step
  1. Your schema (often generated from a Pydantic class) is turned into a grammar that describes every valid output.
  2. At each generation step, the server works out which tokens could legally come next.
  3. All other tokens get their probability set to zero before sampling.
  4. The output is therefore guaranteed to parse and match the schema's structure.
Key details
  • Provider structured-output modes and tool calling build on this; LangChain's with_structured_output chooses the right mechanism.
  • Valid structure doesn't mean correct content. Still validate the values.
  • Open-source servers implement it with libraries such as Outlines or XGrammar.
