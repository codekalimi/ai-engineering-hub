How does structured output (JSON mode, constrained decoding) work?

In one lineEither the model is trained to emit schema-shaped JSON (as in tool calling), or the server restricts which tokens may be chosen at each step so the output must match your schema.

Step by step
  1. Your schema (often generated from a Pydantic class) is turned into a grammar that describes every valid output.
  2. At each generation step, the server works out which tokens could legally come next.
  3. All other tokens get their probability set to zero before sampling.
  4. The output is therefore guaranteed to parse and match the schema's structure.
Key details
  • Provider structured-output modes and tool calling build on this; LangChain's with_structured_output chooses the right mechanism.
  • Valid structure doesn't mean correct content. Still validate the values.
  • Open-source servers implement it with libraries such as Outlines or XGrammar.
Behind the scenes

See it run

A tiny from-scratch version of what really happens. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: plain Python, nothing to install.

python3 · standard library only
# Constrained generation masks out every token the schema does not allow, before each pick.
import json, random
random.seed(0)

VOCAB = ['{', '}', '"sentiment"', ':', '"pos"', '"neg"', 'Sure!', 'Here', ',']
# Step 1: the schema {"sentiment": "pos" | "neg"} becomes a grammar: what may come at each position
GRAMMAR = [['{'], ['"sentiment"'], [':'], ['"pos"', '"neg"'], ['}']]

def model_scores(so_far):
    # the unconstrained model would love to chat first
    return {t: (5.0 if t in ('Sure!', 'Here') else random.uniform(0, 2)) for t in VOCAB}

out = []
while len(out) < len(GRAMMAR):
    # Step 2: work out which tokens could legally come next
    legal = GRAMMAR[len(out)]
    scores = model_scores(out)
    wanted = max(scores, key=scores.get)
    # Step 3: every other token gets probability zero (score -inf) before picking
    masked = {t: (s if t in legal else float("-inf")) for t, s in scores.items()}
    pick = max(masked, key=masked.get)
    print(f"model wanted {wanted:12} allowed {legal} -> {pick}")
    out.append(pick)

# Step 4: guaranteed to parse
text = "".join(out)
print("output:", text, "->", json.loads(text))

Watch it in a real system
  • LangChain: model.with_structured_output(MySchema, include_raw=True) returns the raw message, the parsed object and any parsing error, so you see what came back.
  • Print MySchema.model_json_schema() (Pydantic) to see the JSON Schema that is sent to the API.
  • Self-hosted: vLLM and llama.cpp support grammar/JSON-schema guided decoding; compare output with and without it on a small model.
