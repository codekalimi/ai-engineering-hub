How does attention work?

In one lineEach token makes a query, a key and a value. It compares its query with earlier tokens' keys to decide how much to pay attention to each, then takes a weighted mix of their values.

Step by step
  1. Each token vector is multiplied by three learned matrices, giving a query (what I'm looking for), a key (what I contain) and a value (what I pass on).
  2. Each token's query is compared with every token's key using a dot product, scaled by √d to keep values stable.
  3. A causal mask blocks attention to future tokens, so generation stays left to right.
  4. Softmax turns the scores into weights that add up to 1.
  5. The output for each token is the weighted sum of the values: information from relevant tokens is mixed in.
  6. Multi-head attention runs this many times in parallel with different projections, so different heads can track different relationships.
Key details
  • Prefill cost grows with the square of the sequence length, which is why very long prompts are expensive.
  • Grouped-query attention (GQA) shares keys and values across heads, shrinking the KV cache.
  • FlashAttention computes exactly the same result with far less memory traffic.

Use it

What you'd write at work

You rarely write attention yourself: models call PyTorch's fused kernel, which picks FlashAttention-style implementations when the hardware supports them.

python
import torch
import torch.nn.functional as F

torch.manual_seed(0)
batch, heads, tokens, head_dim = 1, 2, 4, 8
q, k, v = (torch.randn(batch, heads, tokens, head_dim) for _ in range(3))

out = F.scaled_dot_product_attention(q, k, v, is_causal=True)   # one fused call
print(out.shape)   # same shape as q: one new vector per token per head
# In a model config you only choose the implementation, e.g.
# AutoModelForCausalLM.from_pretrained(name, attn_implementation="sdpa")

✓ Ran with torch 2.15.0.

Under the hood

What the library does for you, with its real classes

The same computation by hand, as it happens inside every layer: projections, scaled scores, causal mask, softmax, weighted sum, heads.

python
import math
import torch
import torch.nn.functional as F

torch.manual_seed(0)
B, T, d_model, H = 1, 4, 16, 2
hd = d_model // H
x = torch.randn(B, T, d_model)                                   # 4 token vectors
W_q, W_k, W_v, W_o = (torch.nn.Linear(d_model, d_model, bias=False) for _ in range(4))

def heads(t):                                                    # Step 6: split into H heads
    return t.view(B, T, H, hd).transpose(1, 2)

q, k, v = heads(W_q(x)), heads(W_k(x)), heads(W_v(x))            # Step 1: query, key, value
scores = q @ k.transpose(-2, -1) / math.sqrt(hd)                 # Step 2: dot products / sqrt(d)
future = torch.triu(torch.ones(T, T, dtype=torch.bool), diagonal=1)
scores = scores.masked_fill(future, float("-inf"))               # Step 3: causal mask
weights = scores.softmax(dim=-1)                                 # Step 4: rows add up to 1
out = weights @ v                                                # Step 5: weighted sum of values

print("head 0 weights (row = token, column = token it looks at):")
print(weights[0, 0].detach().numpy().round(2))
same = torch.allclose(out, F.scaled_dot_product_attention(q, k, v, is_causal=True), atol=1e-6)
print("same as the fused kernel:", same)
y = W_o(out.transpose(1, 2).reshape(B, T, d_model))              # join the heads, project back
print("layer output:", tuple(y.shape))

✓ Ran with torch 2.15.0.

From scratch

The idea in plain Python, no libraries

A tiny version of the mechanism. The Step comments match the numbered steps above. Save it as a .py file and run python3 file.py: nothing to install.

python3 · standard library only
# Single-head causal attention over 3 tokens, written out by hand.
import math

tokens = ["The", "cat", "sat"]
# Step 1: each token has a query, key and value vector (normally token vector x learned matrices)
Q = [[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]]
K = [[1.0, 0.0], [0.2, 1.0], [0.9, 0.8]]
V = [[1.0, 0.0], [0.0, 1.0], [0.5, 0.5]]
d = len(Q[0])

def softmax(xs):
    m = max(xs)
    e = [math.exp(x - m) for x in xs]
    return [x / sum(e) for x in e]

for i, tok in enumerate(tokens):
    # Step 2: score = query . key / sqrt(d)
    # Step 3: causal mask - only tokens at or before position i are scored
    scores = [sum(q * k for q, k in zip(Q[i], K[j])) / math.sqrt(d) for j in range(i + 1)]
    # Step 4: softmax turns the scores into weights that add up to 1
    w = softmax(scores)
    # Step 5: the output is the weighted mix of the value vectors
    out = [sum(w[j] * V[j][c] for j in range(i + 1)) for c in range(d)]
    looks = ", ".join(f"{tokens[j]} {w[j]:.2f}" for j in range(i + 1))
    print(f"{tok:>4} attends to [{looks}] -> output {[round(x, 2) for x in out]}")
# Step 6: multi-head attention = this, several times in parallel with different Q/K/V matrices

✓ Ran with plain Python 3.9+.
